객체 지향 프로젝트

**주제**
여행 일정 관리 프로그램
핵심 기능

 > 로그인 / 사용자 관리: ID, 비밀번호, 이름, 여행 선호 스타일(액티비티, 먹방, etc..)
 사용자가 로그인한다
  실패하면 재입력 또는 회원가입
  성공하면 메인화면 이동

>>메인화면에서 다음 메뉴 중 하나 선택
 1. 여행 일정 관리
 2. 여행지 검색
 3. 여행 공유
 4. 여행 후기 작성
 5. 종료(로그아웃)

 >>> 여행 일정 관리: 일정 추가/수정/삭제, 조회
 일정 추가하면 날짜, 여행지, 설명, 사진 첨부 가능
 일정 조회 시엔 리스트로 출력됨

 >>> 여행지 검색:
 이름, 지역, 카테고리(자연 위주, 맛집 위주, 관광 위주)로 검색 가능하게
 여행지 정보 확인 기능(사진, 후기, etc)

 >>> 여행 공유
 친구 선택하고 일정 공유 가능
 -> 공유된 일정 확인 기능

 >>> 여행 후기 작성
 완료된 여행은 여행기록에 저장됨, 사용자는 여행기록에 있는 여행 후기 작성 가능
 후기(별점, 사진, 맛집, 관광지,...)

 >>> 종료
